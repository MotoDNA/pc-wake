# 📱 PC 원격켜기 (PC Wake)

휴대폰 버튼 하나로 **집·사무실의 꺼진 컴퓨터를 밖에서 켜는** 무료 안드로이드 앱입니다.
공유기 종류(ipTIME, KT, SK, LG, TP-Link …)와 상관없이 작동하고, **공유기 설정(포트포워딩·DDNS)이 필요 없습니다.**

## ⬇️ 다운로드

| 무엇 | 어디에 설치 | 받기 |
|---|---|---|
| **PC-Wake.apk** | 안드로이드 폰 / 남는 폰·탭 | [최신 버전 받기](https://github.com/MotoDNA/pc-wake/releases/latest/download/PC-Wake.apk) |
| **PC-setup.zip** | 켜고 싶은 윈도우 PC | [최신 버전 받기](https://github.com/MotoDNA/pc-wake/releases/latest/download/PC-setup.zip) |

> 아이폰은 아직 지원하지 않습니다. (애플 정책상 GitHub에서 앱을 설치할 수 없음)

## 🧭 어떻게 작동하나요?

```
[내 폰 = 리모컨]  --인터넷-->  [무료 알림 서버 ntfy]  --인터넷-->  [남는 폰/탭 = 중계기]
                                                                  │ 같은 공유기(와이파이)
                                                                  ▼
                                                        [꺼진 PC] 매직 패킷 받고 켜짐 ⚡
```

1. 꺼진 PC는 프로그램을 실행할 수 없지만, **랜카드는 작은 전기로 대기**하다가 '매직 패킷'이라는 신호를 받으면 PC를 켭니다. (Wake-on-LAN)
2. 이 신호는 **같은 공유기 안에서만** 전달되므로, PC 옆에 **항상 켜진 남는 폰/탭(중계기)** 을 하나 둡니다.
3. 밖에서 리모컨 버튼을 누르면 → 중계기가 받아서 → PC에 매직 패킷을 보냅니다.
4. PC의 IP를 입력해 두면 **실제로 켜졌는지**까지 알려줍니다.

## 🛠 설치 순서 (처음 한 번만)

### 1단계 · PC 준비 (켜고 싶은 컴퓨터에서)
1. PC를 **랜선으로 공유기에 연결**합니다. (와이파이로만 연결된 PC는 꺼진 상태에서 켤 수 없어요)
2. `PC-setup.zip`을 받아 압축을 풀고 **`START-PC-Setup.bat`** 을 더블클릭 → '예' 클릭.
3. 화면에 나온 **MAC 주소**와 **IP 주소**를 적어 둡니다. (자동으로 복사되니 카톡 '나와의 채팅'에 붙여넣으면 편해요)
4. 화면 안내대로 **BIOS에서 Wake on LAN을 켭니다.** (재부팅 때 Del/F2 연타)

### 2단계 · 중계기 (남는 폰/탭, PC와 같은 와이파이)
1. `PC-Wake.apk`를 받아 설치합니다. ('출처를 알 수 없는 앱' 허용 필요)
2. 앱 실행 → **[이 기기를 중계기로]** → **[중계기 시작]**
3. **[배터리 절전 예외 설정하기]** 를 누르고 '허용'.
4. 삼성 기기: 설정 › 배터리 › 백그라운드 사용 제한 › **절전 예외 앱**에 'PC 원격켜기' 추가.
5. 충전기에 꽂아 두면 끝. 화면에 **QR 코드**가 보입니다.

### 3단계 · 리모컨 (늘 들고 다니는 폰)
1. 같은 APK를 설치 → **[이 기기를 리모컨으로]**
2. **[QR 스캔]** → 중계기 화면의 QR을 비춥니다. ("✅ 중계기 정상 작동 중"이 나오면 성공)
3. **[+ 컴퓨터 추가]** → 1단계에서 적어 둔 MAC·IP 입력.
4. **[전원 켜기]** 를 누르면 끝!

> 가족 폰 여러 대도 같은 QR로 연결할 수 있습니다.

## ❓ 자주 묻는 질문

**켜기 신호는 갔다는데 PC가 안 켜져요.**
- PC가 **랜선**으로 공유기에 연결돼 있나요?
- PC를 종료한 상태에서 **랜 포트 불빛**이 켜져 있나요? 꺼져 있으면 BIOS 설정(Wake on LAN 켜기, ErP 끄기)을 확인하세요.
- 콘센트를 뽑았다 꽂은 직후에는 한 번 PC를 켰다 꺼야 하는 메인보드가 있습니다.
- 중계기(탭)가 **PC와 같은 공유기**에 연결돼 있나요? (게스트 와이파이 ✕)

**"중계기가 대답하지 않아요"가 떠요.**
- 탭이 켜져 있고 와이파이에 연결돼 있는지, 앱에 '실행 중'이 보이는지 확인하세요.
- 배터리 절전 예외가 빠지면 몇 시간 뒤 꺼질 수 있습니다.

**노트북도 되나요?**
- 랜 포트가 있고, 충전기가 꽂혀 있고, BIOS에서 Wake on LAN을 지원하는 노트북만 됩니다.
- USB 랜 어댑터는 '완전 종료' 상태에서 켜기를 대부분 지원하지 않습니다. (절전 모드에서는 될 수 있음)

**안전한가요?**
- 리모컨과 중계기 사이 메시지는 연결 코드 안의 **비밀 열쇠로 서명**되어, 코드를 모르는 사람이 보낸 명령은 무시됩니다.
- 서버를 거치는 내용은 '어떤 MAC 주소를 켜라'는 정보뿐이며, PC 안의 파일·비밀번호와는 관계가 없습니다.
- 코드가 남에게 알려졌다면 중계기 화면에서 **[새 코드 만들기]** 를 누르세요.
- 메시지 전달에는 무료 공개 서비스 [ntfy.sh](https://ntfy.sh)를 사용합니다.

## 🧑‍💻 개발자용

- Kotlin · 안드로이드 8.0(API 26) 이상
- `main` 브랜치에 올리면 GitHub Actions가 자동으로 APK를 빌드해 Releases에 올립니다.
- 앱 서명 키는 저장소에 올리지 않습니다. 저장소 **Settings › Secrets and variables › Actions** 에 `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD` 를 넣으면 자동 빌드가 그 키로 서명합니다.
