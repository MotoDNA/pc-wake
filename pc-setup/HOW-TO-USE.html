PC 원격켜기 사용 설명서

휴대폰 버튼 하나로, 밖에서도 꺼진 컴퓨터를 켜요.

📱내 휴대폰리모컨 (안드로이드)
📟남는 폰·탭중계기 · 밖에서 켤 때 필요
1

컴퓨터 준비하기

켜고 싶은 컴퓨터에서 해요

  1. 이 폴더의 START-PC-Setup 을 더블클릭하세요.

    "이 앱이 디바이스를 변경하도록 허용하시겠어요?" → 예
    파란 "Windows의 PC 보호" 창이 뜨면 → 추가 정보 → 실행

  2. 파란 창에서 설정이 자동으로 끝나고, QR 코드 창이 열려요.

    이 QR 창은 3단계에서 폰으로 찍을 거예요. 그대로 띄워 두세요.

  3. BIOS 설정 (딱 한 번) — 재시작하면서 Del 또는 F2 를 연타해 들어간 뒤, 아래 항목을 Enabled(켜기)로 바꾸고 F10으로 저장하세요.

    ASUSAdvanced › APM › Power On By PCI-E
    MSISettings › Advanced › Wake Up Event Setup › Resume By PCI-E Device
    GIGABYTESettings › Platform Power › Wake on LAN
    ASRockAdvanced › ACPI › PCIE Devices Power On
    완제품·노트북"Wake on LAN" 또는 "Remote Wake Up"

    "ErP" 또는 "Deep Sleep" 항목이 있으면 Disabled(끄기)로 바꿔 주세요.

2

중계기 켜 두기

PC와 같은 와이파이에 연결된 남는 폰·탭에서 해요 · 같은 와이파이에서만 쓸 거면 건너뛰어도 돼요

  1. PC-Wake.apk 를 설치하고 앱을 열어 중계기를 고르세요.

    설치할 때 "출처를 알 수 없는 앱" 허용 화면이 나오면 허용을 눌러주세요.

  2. 중계기 시작을 누르면 "신호 대기 중"으로 바뀌어요. 체크리스트의 설정·허용 버튼도 눌러 주세요.

  3. 충전기에 꽂아 둔 채로 두면 끝. 아래쪽에 리모컨 연결용 QR이 보여요.

3

리모컨으로 켜기

늘 들고 다니는 내 휴대폰에서 해요

  1. 같은 앱을 설치하고 리모컨을 고른 뒤, QR 스캔으로 중계기 화면의 QR을 찍으세요.

  2. 컴퓨터 추가 → QR로 가져오기 → 1단계 PC 화면의 QR을 찍고 저장하세요.

  3. 전원 버튼을 누르면 끝! 초록색으로 바뀌고 "켜짐 확인"이 나오면 성공이에요.

?

안 될 때

  • "신호는 보냈지만 PC가 대답하지 않아요"PC가 랜선으로 연결돼 있는지, PC를 끈 상태에서 랜 포트 불빛이 켜져 있는지 확인하세요. 불빛이 꺼져 있다면 1단계의 BIOS 설정을 다시 확인해 주세요.
  • "중계기가 대답하지 않아요"탭이 켜져 있고, 앱에 "신호 대기 중"이 보이는지 확인하세요. 삼성 기기는 설정 › 배터리 › 백그라운드 사용 제한 › '절전 예외 앱'에 추가해야 오래 켜져 있어요.
  • 노트북도 되나요?랜 포트가 있고 충전기가 꽂혀 있으면 대부분 돼요. 와이파이로만 연결된 컴퓨터는 꺼진 상태에서 켤 수 없어요.
  • QR이 남에게 알려졌어요중계기 화면에서 '새 코드 만들기'를 누르고, 리모컨에서 QR을 다시 찍으세요.
